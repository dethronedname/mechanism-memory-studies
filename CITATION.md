# How to cite

[Machine-readable citation](CITATION.cff) · [Authorship](AUTHORS.md) · [Licensing](LICENSING.md)

If you use the software, experimental protocols, data, or results in research, please cite **Mechanism Memory Studies** and identify the study (PI4, C1, B1, or T1), the source revision or archive hash, and the evidence used.

The sole author is **[chumingyzx](https://github.com/chumingyzx)**, a public pseudonym. There is no associated publication DOI or published repository release at this stage. The [repository](https://github.com/chumingyzx/mechanism-memory-studies) is private for author review; access requires permission. The author-profile link identifies the author.

Suggested citation for this review draft:

> chumingyzx. *Mechanism Memory Studies*. Research software and evidence collection, review draft curated 2026-09-24. https://github.com/chumingyzx/mechanism-memory-studies (private repository).

Include the commit used. When a public release exists, add its actual release version or DOI if assigned. For a numerical claim, also identify the relevant [source record](results/evidence_manifest.json) and [derived comparison](results/derived/TABLES.md). Cite related papers separately when using their methods; their citation is not a substitute for identifying this implementation.

The research citation request is not an additional license condition. Copyright-notice retention under MIT and attribution under CC BY 4.0 remain governed by the [license texts and scope](LICENSING.md).
