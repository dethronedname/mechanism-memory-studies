# How to cite

[Machine-readable citation](../../CITATION.cff) · [Authorship](authors.md) · [Licensing](licensing.md)

If you use the software, experimental protocols, data, or results in research, please cite **Mechanism Memory Studies** and identify the study (PI4, C1, B1, or T1), the commit or source archive hash, and the evidence used.

The sole author is **[dethronedname](https://github.com/dethronedname)**, using a public pseudonym. The repository is available at [dethronedname/mechanism-memory-studies](https://github.com/dethronedname/mechanism-memory-studies).

Suggested citation:

> dethronedname. *Mechanism Memory Studies*. Research software and evidence collection, curated 2026-09-24. https://github.com/dethronedname/mechanism-memory-studies

Include the commit used. No paper DOI or tagged software release is asserted. If a release or DOI is assigned later, cite the actual identifier. For a numerical claim, also identify the relevant [source record](../../results/evidence_manifest.json) and [derived comparison](../../results/derived/TABLES.md). Cite related papers separately when using their methods.

The research citation request is not an additional license condition. Copyright-notice retention under MIT and attribution under CC BY 4.0 are governed by the [license texts and scope](licensing.md).
