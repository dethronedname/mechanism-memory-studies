# Study map and scope

The identifiers are research units, not successive releases of a universally improving architecture. Dates in old filenames are retained as artifact identifiers; use run timestamps and manifests for execution dates.

| Unit | Question / intervention | Evidence type | Main interpretation and limit |
|---|---|---|---|
| PI-1 | Use prescribed future responses as actual recurrent coordinates | New-model learning, followed by GPU trial | No independent advantage over a free latent structured model with the same auxiliary supervision |
| PI-2 | Split mechanism context from dynamic state for heterogeneous components | New-model learning | Long-horizon/calibration-use signal with short-horizon cost; complete quality gate not passed |
| PI-3 | Separate initialization from dynamics; wait and re-excite | Frozen-model interventions and conditional mathematics | Retention is distinct from correct writing/reading; not a new training experiment |
| PI-4 CPU | Reweight behavior differences and calibration consistency | Development learning | Limited screen, not the later GPU outcome |
| PI-4 GPU | Same structural 2×2 comparison with fuller training | Exploratory learning | `LIMITED_ARCHITECTURE_SIGNAL` numerically; legacy replay validity remained `INCONCLUSIVE`, later task-level replay supported the effects |
| PI-4 C1 | Freeze recipe; three new generated datasets | Confirmation within the same simulator | `PARTIAL_REPLICATION`: mechanism direction repeated, full gate 1/3 |
| PI-4 B1 | Continuous calibration for GRU/graph-GRU/ODE; modest wider capacity | Baseline challenge, equal updates | `MIXED_TRADEOFF_NO_DOMINANCE`; unequal fitting costs |
| PI-4 T1 GPU02 | Same locked six methods; 600-second complete-fit cap | Budget-matched challenge | `MIXED_TIME_BUDGET_TRADEOFF`; wide GRU better on mechanism/short tasks, candidate retains some long-horizon quality |

## Repository priorities

**v0.1 default narrative:** PI-4 → C1 → B1 → T1, with model/simulator definitions inherited from PI-2. Small evidence for these four study blocks is already supplied with the repository overlay.

**Historical context:** PI-1/PI-2/PI-3 explain why hypotheses changed. Their frozen code, raw outputs, and mathematical notes can be separate study assets, not mixed into a single leaderboard. Their summaries here are source-derived narrative, not newly reconstructed outcome tables.

**Predecessors:** WickPolyCore, LocalPolyNet/SC-1, and RG units are a separate exploration family. Keep a compact index and optional archived snapshots. Do not sell a Wick theorem as a proof of the later mechanism-memory network.

## What is not another independent sample

An initialization, optimizer restart, calibration swap, scenario, CPU replay, repeated table build, or model checkpoint is not an independent data-generating system. Three generated datasets remain three draws from one simulator—not three external domains. Across stages, datasets, seeds, schedules, and comparison budgets change; do not draw a single rising “version improvement” curve.
