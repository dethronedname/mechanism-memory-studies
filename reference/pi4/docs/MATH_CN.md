# PI-4：行为监督的数学内容及其边界

## 1. 普通MSE已经包含差分和一致性
设两个机制i=0,1，各有两组不同校准v=A,B。相同查询下，真实轨迹为Y_i，预测为P_iv。令P_i=(P_iA+P_iB)/2，P_bar=(P_0+P_1)/2，Y_bar=(Y_0+Y_1)/2。
对时间/节点/批次的同一内积范数：

L_MSE = (1/4) sum_i,v ||P_iv-Y_i||²
      = ||P_bar-Y_bar||²
        + (1/4)|| (P_1-P_0)-(Y_1-Y_0) ||²
        + (1/8)sum_i ||P_iA-P_iB||².

若L_repeat为两机制的一致性平方差的平均，最后一项等于(1/4)L_repeat。此恒等式在任意预测、标签上逐点成立，不需要高斯、IID或模型正确。
因此本轮新增差分和一致性项只是重新加权，不是原MSE完全缺失的新信息。不允许把“有显式机制损失”直接解释为“原模型没有机制监督”。配对元数据和匹配查询是本轮共同提供的训练设计，不由候选独享。

## 2. 不变不等于有用
让所有P_iv恒为同一函数可以完美满足校准一致性，却不能识别不同机制。因此必须同时保留绝对预测目标和真实部件差分目标，并报告未归一化总体误差。仅差分正确也不能排除所有部件的共同偏差。
原始潜在坐标允许可逆重参数化，惩罚c_A-c_B的大小依赖任意坐标尺度。本轮在可观测未来行为上比较，不增加潜变量距离正则。这并不保证全局辨识，只是消除了一个坐标选择问题。
有限查询的行为一致，只保证这些查询，不保证所有合法控制和全部时间上的系统等价。严格永久不变上下文还要求真实机制恒定，本轮没有研究参数漂移或噪声测量。

## 3. 已知方程的积分辨识正对照
真实方程：q'=p，p'= -k q - beta q³ - d p + u，beta=0.2。
校准可测p、u，但每段初始位置q0未知。令I(t)=integral_0^t p(s)ds，则q(t)=q0+I(t)。积分消去p'后：

p(t)-p(0)-U(t)
+ k(q0*t+A1(t))
+ beta(q0³*t+3q0²*A1(t)+3q0*A2(t)+A3(t))
+ d*I(t) = 0,

其中U=int u，A_j=int I^j。两段校准共享k,d，但有各自q0，得到4个未知数。实现只读取校准I/O，使用一个固定初点、固定100次求解上限的有界最小二乘；没有用真实参数、未来query标签作拟合或选初值。
输入在每个采样区间内常数，因此U按左端输入精确求和；I和A_j用梯形积分近似，参数不可能由数值设计保证精确等于真值。微分噪声被避免，但积分回归仍有离散化误差及可能的病态性。
该参照知道正确物理方程、beta、质量、采样假设和重置为零；神经模型不知道这些参数化。它是强先验下的“这份I/O是否含有机制信息”的正对照，不是公平的神经架构速度/精度基线。

## 4. 必须保留的不可识别情形
若校准初态q=p=0且始终u=0，无论k,d为何校准I/O都相同，后续非零驱动却可不同。这时没有任何只读取该校准的编码器可以区分参数；加一致性或差分损失不会制造信息。本轮校准含随机初态与非零驱动，不用全局不可能性替代实际充分性检查。

## 5. 理论与实验的联系
平方风险分解指导公平对照；积分恒等式指导信息充分性检查；固定c的储能关系仍沿用原PI2。三者均不保证新目标降低测试误差，也不构成新架构定理。
