# PI-4：行为约束的机制学习 — 执行前协议

2026-09-20。问题依据PI-2/PI-3提出，本轮新数据、新训练，不称未接触旧证据的预注册确认，不改变PI-2原停止决定。

## 问题与归因
主2×2：固定2维上下文+2维动态状态 vs 自由4维状态；普通平方损失 vs 行为加权损失。普通条件ODE+行为损失作附加对照。五种方法全部获得同样两套校准、配对标签、查询历史、未来控制和连边，不能给候选独享机制参数、内部状态或更多未来分支。
原pi2/models.py和simulator.py逐字复用，推理图未新增变量、控制器、记忆码或辅助头。主状态四标量，训练参数量不同必须报告。行为损失不是新架构，不宣称原创算法。

## 数据
部件参数在原区间重新抽取；每套校准含2段48点接口I/O，两套校准的初态和输入独立。同一世界两套校准共享机制。每个重置对的两个世界使用匹配校准初态/驱动，只改变机制。
一般训练：2/4节点链、16点历史、16步预测及原短探针监督。
重置训练：已知准确静止，两套校准，32步同输入再激励。未来响应差异是观测标签，不是参数标签。训练等待0或16步。所有方法都实际滚动隐状态，不选择性跳过等待。
测试：新4/8节点环、8节点长64步；独立部件与4节点环从静止再激励64步，等待0/256；同机制对为零差分边界。测试256步等待不用于选模。只评一次全部测试，旧PI2/PI3测试锁不动。

## 损失
一般任务保留旧MSE、初值、两类短探针项；两套校准均前向并监督，所有模型相同。
重置普通损失：两世界两校准的平均轨迹MSE+0.25初始输出MSE。
行为损失额外加0.25×部件差分预测误差（用两校准预测平均形成差分），以及0.25×同部件不同校准预测不一致。
一般/重置误差除以各自训练输出能量；差分除以训练集全局差分能量；一致性除以对应训练输出能量。分母下限1e-6，不对单个测试对调整。系数不按结果改变。
同一模型的两个目标使用相同初始化、批次和等待序列。

## 运行与选模
CPU：5方法×3初始化×240更新，不搜索超参数。GPU：5×3新初始化×1600更新、新数据；不能将CPU/GPU差异归为硬件收益。
奇数步一般轨迹、偶数步重置配对。初始化也纳入验证选择。选模只用两类未加权验证NMSE各占一半；重置验证平均等待0/16。不能用测试差分挑检查点。
主预测仅用校准A，不做双校准集成；B用于一致性诊断。报告完整轨迹NMSE、差分E_delta、换同机制校准后的预测变化、等待后变化。三个初始化不等于三个独立数据集。

## 判断
行为目标有效而固定/自由相近：是学习规则价值，不是新架构。
固定行为相对自由行为在两个静置后差分场景的几何平均至少改善10%，一般场景各项配对中位退化不超过5%，至少2/3初始化综合方向一致：才记有限架构信号，不称确认。
差分好、总体预测差：记录取舍。不通过则不自动增加码维度、等待长度、训练预算或优化器。GPU是一轮有边界完整任务，不做BF16/compile/计时矩阵。

## 工程与范围
CPU每进程420秒、20秒收尾，整轮8000秒；GPU每进程900秒、20秒收尾，整轮14400秒。均为资源上限，不是耗时预测。必要比较不完整则INCONCLUSIVE，不读取测试标签。
无CUDA请求GPU返回NOT_RUN和退出码2，不回退CPU。保留CUDA_VISIBLE_DEVICES，仅用已有分配cuda:0，不提交调度器作业或改环境。
积分灰箱辨识参照已知正确ODE形式及系数0.2，仅用校准I/O估计未知参数/初态，是强物理先验的信息充分性正对照，不进公平架构排行榜。
全部结果限定：一个模拟器、一个数据划分、无测量噪声、参数区间内新部件、同更新数而非严格同墙钟。
