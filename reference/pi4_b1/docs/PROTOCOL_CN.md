# PI-4 B1：持续校准信息的基线挑战

日期：2026-09-21。协议 `PI4-B1-v0.1-20260921`。本协议是看过C1部分重复结果后提出的前瞻性基线挑战，不冒充从未接触旧证据的预注册。不是PI-5，不增加候选模块，也不追溯修改C1。

## 1. 要回答的问题

旧自由四维基线只在初始化时接收校准编码，此后丢弃。C1说明固定记忆配合行为损失有重复的机制差分收益，但一般短期预测有代价。B1检验：允许常规方法每步读取相同校准信息、并提供较合理的状态容量后，当前候选是否仍有独立的质量优势。

B1不是主流架构完整排行榜。新实现使用GRUCell、消息传递及条件神经ODE这些成熟计算单元，但属于本任务的自实现适配。没有完整复现GNS、SANODEP或MSPD，没有Transformer/Mamba比较，不允许使用“已经超过所有主流架构”表述。来源与差异见SOURCES.md。

## 2. 原内容冻结与新增内容

`pi2/`、`pi4/`的10份原Python源码逐字保留，哈希见provenance/ORIGINAL_CORE_SHA256.json。fixed_behavior候选及free_behavior旧主对照的计算图、损失、数据生成、初始化、配方均不改。

新实现只在`bc1/`。`bc1/experiment.py`从原训练/评分执行器派生：仅替换模型工厂与方法注册表，并追加学习率和峰值分配显存记录。目标函数和验证选择仍调用原文件。`bc1/numerics.py`从C1回放派生，适配新工厂、去掉本轮不存在的MSE/behavior成对初始化检查，其数值阈值不放宽。源码差异见provenance/DERIVED_CODE.patch。

全部历史编码器宽度16。新宽模型中间层32，gru4中间辅助头沿用16。新模型每步输出与更新都能读取校准编码；无额外真实参数、内部状态、身份标签、未来观测。支持校准片段的均值池化保持片段顺序不变性。主观“合理容量”仍是有限选择，32维未声称是最优状态数。

两层比较不能混为一谈：gru4是状态预算机制对照（并非完全等参数）；32维组是较充足资源的实用竞争对照（不能由结果单独归因于容量或结构）。所有参数量、成本公开，不使用隐含等预算说法。

## 3. 新模型的具体前向式

令c=支持记录编码，h=当前动态状态，y=g(h,c)，u=e-Ky（以实现的行向量形式`external-y@k.T`计算）。条件GRU使用：

`h_next = GRUCell(concat(c,u,y), h)`。

c在所有步保持不变，且每步可读；标准GRUCell使用当前固定采样间隔，不假装是可任意步长的连续时间模型。

图GRU额外构建`m_i=sum_j |K_ij| psi(h_i,c_i,h_j,c_j,K_ij)`并输入同类GRUCell。无边处贡献严格为零；不使用节点ID或绝对位置。它是单轮消息传递的任务适配，不是GNS的Encode–Process–Decode网络全复现，也没有导入GNS的训练噪声或作者超参数。图对照能交换更多潜在信息，这是明确给予其的表达选择，而非等同于仅交换物理端口。

条件ODE使用`h_dot=MLP(h,c,u)`、线性读取`y=g(h,c)`；用与候选相同dt和Heun积分。它不强制能量耗散。c永久保留并不能保证信息准确；这恰好是待检验的问题。

所有模型实现同一个未来探针辅助接口；GRU/图模型使用自身离散更新生成探针，ODE使用自身积分。主训练loss、系数、标签、批次规则完全共用。

## 4. 开发与独立比较

候选与旧free保持原learning_rate=0.003，不搜索，不对C1反馈修正损失。四个新增基线在一个独立开发数据集上，各试0.001、0.003两个学习率，共8次拟合。用原未加权一般/重置验证NMSE选一个学习率，平分按较小学习率确定性打破。全部开发成功后一次性写HYPERPARAMETER_LOCK.json。

这种搜索额度不对称有意对新基线宽容：不是候选和基线同搜索预算结果。若基线更好，可以质疑当前候选的实用必要性，但不能排除原候选其他未试配方；若候选更好，也只超过这一有限对照与搜索范围。

开发只读取训练/验证，生成但不使用开发测试；不因开发胜负提前停止、筛除模型或更换宽度。任何开发失败使流程INCONCLUSIVE，不改成“没收益”，不跳过失败学习率。

随后在三套全新数据上，每套三初始化、六模型，共54次拟合。开发与比较合计62次。全部固定1600步，每100步及第0步验证。初始化、权重衰减、loss系数、batch、clip与C1相同。学习率例外只来自上述新基线DEV锁。

数据随机基点dev=1921101、b01=2021101、b02=2121101、b03=2221101；源生成器最大偏移205，彼此不重叠，亦与前述C1的921101/922101/923101不重叠。初始化dev=937，比较=941/947/953。

三套比较数据的全部拟合正常完成后，才统一释放测试。缺失、BUDGET_STOP、TIMEOUT、非有限值都不能排除后只展示幸存模型。旧C1目录、权重、测试锁不触碰。

## 5. 数据与范围

同一非线性振子模拟器、同一参数分布。训练/验证/测试256/32/48组；16点查询历史；每套校准2段48点；一般训练16步、重置32步；训练等待0/16，测试等待0/256；一般测试ring4、ring8、long8和独立/重组/零差分边界全部保留。

参数/隐状态仍仅在scoring_only内。工作流隔离不等于密码学隔离。所有模型拥有相同校准轨迹和行为/未来探针监督，无测试教师强制。

## 6. 判定，不能用测试集挑一个赢家

逐数据集、逐对照完整计算候选/对照的配对误差比，不建立一个看测试结果挑出的“最佳对照”来报告。

沿用原方向的门槛：等待256步两个机制差分场景的几何平均比≤0.90；ring4/ring8/long8各自三初始化中位比≤1.05；至少2/3初始化的机制综合比<1。三套数据都分别报告。

另一个预先定义的描述性5%匹配门槛：对照/候选机制综合比≤1.05，且对照/候选各一般场景的中位比≤1.05。这不是统计等效性或非劣效检验；三个数据集不能保证足够检验功效。

* `LIMITED_COMPETITIVE_SIGNAL`：候选对本轮全部对照，在全部新数据通过原效应+保护门槛。仍非全领域胜出。
* `BASELINE_REPRODUCES_SIGNAL`：至少一个新增基线在全部三套数据都满足5%匹配门槛。说明这一试验内可用较普通计算替代，不是特殊结构永远无价值的定理。
* `MIXED_TRADEOFF_NO_DOMINANCE`：其余完整情形；保持任务取舍，不自动调loss或追加数据。
* 任何完整性/数值失败、缺失：`INCONCLUSIVE`，不是无学习价值。

数值边界±0.001内保持敏感标记，不挪动门槛。CPU/GPU回放改变任一判定也保持INCONCLUSIVE。

普通/错机制/同机制换校准的全部记录，以及E_delta绝对值，都必须呈现。E_delta=1可以意味着不区分机制。不能只比较一个坏基线的相对改善。没有统计显著性或稳定辨识承诺。

## 7. 成本与GPU

主终点是同更新数/同数据条件下的质量，**不是严格同总时间**。新基线两次LR的开发成本全部记录并回传。每个训练记录父进程墙钟、训练净时、参数/状态量和峰值CUDA allocator内存；运行环境和随机顺序保留。没有吞吐加速或节省显存主张。

实际CUDA GPU是正式任务执行要求，沿用已分配的单卡A100即可；80GB不是实测最低需求。保留CUDA_VISIBLE_DEVICES，仅逻辑cuda:0，不自动调度、多卡或重装环境。FP32 eager、关闭TF32，没有BF16/compile扫描。

62次拟合每进程900秒，其中20秒收尾；总72000秒（20小时）硬上限含数据、开发、失败、评估、CPU重放。后处理预留10800秒，剩余不足不启动新拟合。62×900=15.5小时是极端逐进程预算和，不是预计耗时；任何资源先到则PARTIAL，不自动续跑。这比C1多8次开发和9次比较，范围在运行前明确固定。

## 8. 数值与交付

新形状/新模型真实训练路径做有限CPU32/CUDA32/CPU64 loss、原始梯度、裁剪后AdamW一步与矩状态对照。新方法两个实际LR都检查，旧方法0.003检查，总30组路径。沿用C1数值阈值，不靠放宽容差让新基线通过。

所有正式预测在拟合后完整CPU32回放，每权重固定reset_iso等待256前2对做FP64探针；旧逐元素标签与C1预先分层的任务保真标签并列。模型构造来源不同但训练loss同源；回放共用模型源码，不冒充独立重写。

CPU烟雾测试使用小数据/两步拟合，覆盖8次DEV+6次比较、验证锁定、测试释放、评分和回放；它不提供任何学习收益或GPU速度证据。无CUDA即保存62项NOT_RUN并退出码2。

`collect`保留全部源码、权重、预测、LR搜索、曲线、失败和决策。仅排除可再生仿真数据并附原数据内容哈希。历史原始结果不改写。本轮无自动后续实验。
